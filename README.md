# Smart MCQ Solver

Smart MCQ Solver is an NLP-based machine learning project developed to predict the correct answers for multiple-choice questions with five options (A–E).
The project compares multiple approaches, including a Neural Network from scratch, fine-tuned RoBERTa, and Sentence Transformer (all-MiniLM-L6-v2). The models rank the five options and predict the Top-3 answers, evaluated using MAP@3, along with accuracy and F1-score.

Tech Stack:
Python
PyTorch
RoBERTa
Sentence Transformers
Scikit-learn
Weights & Biases (W&B)
